### 2. THE ANCHOR BUG — found, fixed, database re-downloaded

The per-game query named a team, which made it the ANCHOR, so TruMedia
answered every team-scoped column from that team's point of view — **including
on the opponent's rows**. Batches were grouped by home team, so every away side
in the database wore the home side's identity.

**21 columns on 4,276,373 rows.** `teamAbbrevName` wrong on 49.3% of all rows;
`MatchState` inverted on 2.28M; **every away team showed ZERO assists.**

The fix was deleting one clause — `WHERE ((team.teamId = 'X'))`. With no team
named, TruMedia returns each event once per side, each copy carrying that
side's own values; keep the `is_team` copies.

**Resolved.** 5,394 games, 0 still anchored, away assists 4,566 where they
were 0. Full detail in `memory/project_anchor_bug.md` — read it before
touching the downloader.
